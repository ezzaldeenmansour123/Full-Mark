## البناء والتشغيل

```bash
flutter pub get
flutter analyze
flutter test
flutter run                       # على جهاز/محاكي
flutter build apk --release --split-per-abi   # APK خفيف لكل معمارية
```

- **Flutter المستقر:** 3.50.1 مع Dart 3.14.0 (تم التحقق 2026-11-25).
  الحد الأدنى في `pubspec.yaml` محافظ: Flutter `>=3.22` و Dart `>=3.4`.
- **CI:** `.github/workflows/build-apk.yml` — Java 17 + Flutter stable 3.50.1،
  ثم فحص عدم وجود إذن INTERNET في الـ manifest، و`analyze` و `test` و
  `build apk --release --split-per-abi`، ثم بوابة حجم تفشل البناء إن تجاوز
  أي APK ‏100 MB، ثم رفع الـ APK. الـ workflow كما هو — جاهز للرفع دون تعديل.
- **توقيع الإصدار:** غير مضبوط بعد — CI يستخدم توقيع debug حاليًا.
  قبل أي توزيع حقيقي: أضف keystore خاصًا كـ GitHub secret ولا تضع أي مفتاح في المستودع.

## قاعدة البيانات (الإصدار 2 — `abqariya.db`)

`subjects` ، `units` ، `lessons` ، `stages` ، `questions` ، `exam_results` ،
`attempts` ، `progress` (صف لكل كيان: مادة/وحدة/درس/مرحلة) ، `achievements`
(كتالوج 7 إنجازات) ، `review_queue` (SM-2) ، `content_packs` ، `app_meta`
(الإعدادات + إجماليات اللاعب — لا جدول `settings` منفصل).
عند أول تشغيل يُزرع هيكل منهج صنعاء 2027 (53 وحدة / 400 درس، هيكل فقط
بلا أسئلة) من `assets/data/curriculum.json` عبر `seedCurriculumIfEmpty()`؛
وجدول `questions` يبقى فارغًا حتى تصل الكتب المعتمدة أو إذن الوزارة.
ترقية v1 -> v2 في `onUpgrade` تحفظ إعدادات اللاعب وإجماليات XP/النجوم
والإنجازات المفتوحة، وتجمّع المحاولات القديمة في عدّادات (انظر
`lib/db/database.dart` — v1 لم تُشحن على أي جهاز، فالترقية دفاعية).

- المستوى: `1 + XP ~/ 500` — انظر `levelForXp` في `lib/core/progress_store.dart`.
- المنهج المرجعي: **نسخة صنعاء طبعة 2027** (قرار المستخدم 2026-11-25) —
  انظر `docs/CURRICULUM.md` و`assets/data/curriculum.json`.
- قاعدة فتح العوالم: الأول مفتوح؛ كل عالم لاحق يُفتح عند إحراز أي تقدّم في سابقه.

## القيود الصلبة (لا تُكسَر)

- **بلا إنترنت:** لا إذن `INTERNET` في `AndroidManifest.xml`، لا `http`، لا Firebase،
  لا إعلانات، لا حسابات، لا خوادم، لا ذكاء اصطناعي سحابي.
- **APK ≤ 100MB:** رسم إجرائي فقط في v1 — بلا محرك 3D وبلا فيديو وبلا أصول ثقيلة.
- **صدق المحتوى:** لا أسئلة منهجية مخترعة؛ ما لم يُعتمد يظهر «قيد الإعداد».

## ما لم يُختبر محليًا

⚠️ **لا يوجد Flutter/Dart SDK في بيئة البناء هذه** — لم يُنفَّذ أيٌّ من:
`flutter analyze` أو `flutter test` أو `flutter build` أو أي تشغيل على جهاز.
الكود مكتوب بعناية بلغة Dart الاصطلاحية، لكن أول تشغيل حقيقي يجب أن يكون
عبر GitHub Actions (الـ workflow أعلاه) أو على جهاز مطوّر مثبّت عليه Flutter 3.50.1.
لا يُدَّعى نجاح أي بناء قبل ظهور نتيجته في CI.

ملاحظات للتحقق في أول تشغيل CI:
- `flutter_lints: ^5.0.0` — إن فشل `pub get`، اخفضه إلى أحدث إصدار متوافق مع stable.
- Flutter 3.50 أعلن إهمال مكتبتي `material.dart`/`cupertino.dart` المضمّنتين لصالح
  حزم `material_ui`/`cupertino_ui` المستقلة؛ الكود هنا ما زال يستخدم المسار القياسي
  ويجب أن يبني مع تحذيرات إهمال فقط — إن غيّر CI ذلك، تُراجَع الواردات.
- أيقونات التشغيل (`mipmap/ic_launcher.png`) غير مضمّنة؛ الـ workflow يستدعي
  `flutter create . --platforms android` كبديل احتياطي لتوليدها إن غابت.
